Excel Sales Automation System

A Python-based Excel sales automation system that transforms raw sales data from multiple branch Excel files into cleaned datasets, analytical reports, formatted workbooks, charts, and an interactive-style management dashboard.

Overview

This project automates a complete sales reporting workflow using Python.

Instead of manually combining Excel files, cleaning inconsistent data, calculating revenue, creating analysis tables, formatting reports, and building charts, the entire process is handled automatically through a modular Python pipeline.

The system accepts multiple branch-level Excel files, validates and cleans the data, performs sales analysis, and generates professional Excel reports.

Installation

Clone the repository and navigate into the project directory.

Install the required dependencies:

pip install -r requirements.txt
How to Run
Place the branch Excel files inside the input/ directory.
Make sure the files contain the required sales columns.
Run:
python main.py
The generated files will appear inside the output/ directory.

Error Handling

The system includes basic safeguards for common problems.

For example:

If no Excel files are found in the input directory, the loader raises an error.
If required columns are missing, validation stops the pipeline.
If no valid records remain after cleaning, the cleaning stage raises an error.

This prevents invalid data from silently producing incorrect reports.
